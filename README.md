# MihomoBar

Лёгкий значок в строке меню (macOS) и в трее (Windows) для [mihomo](https://github.com/MetaCubeX/mihomo) (Clash Meta) с обязательным TUN.

- Конфиг по ссылке-подписке или локальный файл; обновляется при каждом запуске, при ошибке используется прежний.
- «Обновить конфиг и перезапустить», откат к прежнему конфигу, проверка IP выхода, скорость, выбор исходящего прокси.
- Автоперезапуск (5 попыток), затем аварийная блокировка интернета до ручного выхода из программы. Это **kill switch**: он включён по умолчанию, выключается пунктом меню «Kill switch…»; тогда после 5 неудач прокси просто остановится с уведомлением, интернет не блокируется.
- Обновления: проверка при запуске (раз в сутки; отключается пунктом «Проверять обновления автоматически») и вручную «Проверить обновления…». Файл скачивается из GitHub Releases и проверяется по подписи ECDSA P-256 списка `SHA256SUMS.txt` (открытый ключ вшит в приложение) и SHA-256; затем приложение заменяет себя и перезапускается, прокси продолжает работать, настройки сохраняются.
- Ядро ставится само (GitHub Releases, проверка SHA-256) и обновляется из веб-панели штатно: файл всегда называется `mihomo`.

## Настройки

В самом приложении настроек почти нет: ссылка на конфиг, kill switch, автообновление и автозапуск. Всё остальное — выбор узлов, правила, режимы, обновление ядра, подписки и т. д. — делается через **веб-панель** ([zashboard](https://github.com/Zephyruso/zashboard); пункт меню «Открыть панель»), поэтому в вашем конфиге **обязательна** такая секция:

```yaml
external-controller: 0.0.0.0:порт   # например 0.0.0.0:9090
secret: 'secret'                     # обязательно задайте свой, раз панель слушает 0.0.0.0
external-ui: ./ui
external-ui-url: "https://github.com/Zephyruso/zashboard/releases/latest/download/dist.zip"
external-controller-cors:
  allow-private-network: true
  allow-origins:
  - '*'
```

Без `external-controller` приложение не увидит ядро: не будут работать скорость, исходящий прокси, проверка IP и кнопка «Открыть панель». `external-ui-url` позволяет ядру само скачать панель при первом запуске. Приложение обращается к ядру по `127.0.0.1` и берёт порт и `secret` из этой секции; порт прокси берётся из `mixed-port` (по умолчанию 7890).

## macOS
Нужен Xcode Command Line Tools (`swiftc`); собирается универсальный бинарь (arm64 + x86_64), минимум macOS 14.
```
./build.sh      # собирает MihomoBar.app
./build.sh dmg  # то же + MihomoBar.dmg
open MihomoBar.app   # при первом запуске предложит установить root-хелпер (или ./install.sh вручную)
```
Хелпер `mihomo-ctl` ставится в `/usr/local/libexec`, sudoers разрешает без пароля только его. Блокировка — `pf` anchor `com.apple/mihomobar`.
Аварийно: `sudo /usr/local/libexec/mihomo-ctl unblock`.

## Windows
См. [windows/README.md](windows/README.md). Сборка — `windows\build.cmd` (штатный .NET Framework 4, SDK не нужен).

## Готовые сборки
Скачайте из Releases: `MihomoBar.dmg` (macOS, универсальный: Apple Silicon и Intel) или `MihomoBar-windows-x64.zip` / `MihomoBar-windows-arm64.zip` (Windows под вашу архитектуру).
- **macOS** (14+, универсальная сборка Apple Silicon + Intel; Intel-часть не проверялась на реальном Mac): откройте DMG, перетащите `MihomoBar.app` в «Программы». Приложение не нотаризовано (подпись ad-hoc), поэтому один раз выполните в терминале `xattr -cr /Applications/MihomoBar.app` (или «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть»). При первом запуске приложение само предложит установить root-хелпер (системное окно пароля), затем попросит ссылку на конфиг.
- **Windows:** `MihomoBar.exe` не подписан сертификатом издателя — SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае». Перед распаковкой можно снять пометку: свойства zip → «Разблокировать».

## Известные ограничения
- Аварийная блокировка на macOS (`pf` anchor `com.apple/mihomobar`) вживую протестирована ограниченно — держите под рукой `sudo /usr/local/libexec/mihomo-ctl unblock`.
- Клики по меню и уведомления в автотестах не проверялись; на реальном x64-ПК с Windows сборка не запускалась (проверено на ARM64 в виртуальной машине).

## Выпуск релиза (для автора)
Версия — файл `VERSION` (общая для macOS и Windows). Собрать `windows\build.cmd` в Windows, затем `./release.sh` на Mac: соберёт DMG и zip, подпишет `SHA256SUMS.txt` ключом `~/.config/mihomobar/update-signing-key.pem` и напечатает команду `gh release create`. Ключ нельзя терять или менять: открытый ключ вшит в оба приложения (`MihomoBar.swift`, `windows/MihomoBar.cs`), иначе старые установки перестанут принимать обновления. Имена файлов релиза (`MihomoBar.dmg`, `MihomoBar.exe`, `MihomoBar-windows-x64.zip`, `MihomoBar-windows-arm64.zip`) использует обновление. Первый релиз с этим кодом нужно ставить вручную.
