# MihomoBar для Windows

Значок в трее для mihomo с обязательным TUN. Один exe (C# 5, штатный .NET Framework 4.x — отдельный рантайм не нужен),
запускается от администратора (манифест). Функции те же, что у macOS-версии: подписка по ссылке или локальный файл,
обновление при каждом старте, откат к прежнему конфигу, автоперезапуск (5 попыток), аварийная блокировка интернета,
скорость, проверка IP, диагностика.

## Ядро mihomo: установка и обновление
- Рабочее ядро всегда `%ProgramData%\MihomoBar\core\mihomo.exe` (+ `wintun.dll`). Имя фиксированное, папка пишется только
  администратором: встроенное обновление из панели (`POST /upgrade`) заменяет файл на месте, процесс перезапускается сам.
- Если ядра нет или оно не запускается, при включении прокси ставится копия из пакета (`core\x64|arm64\` рядом с exe),
  а если и её нет — последний релиз скачивается с GitHub (проверка SHA-256 из метаданных GitHub; wintun — по закреплённой сумме).
- Копия из пакета заменяет рабочее ядро **только если новее** — версию, обновлённую из панели, она не затирает.
- Архитектура определяется по машине (ARM64/x64), а не по процессу.

## Состав (`dist\`)
- `MihomoBar.exe`
- `core\x64\{mihomo.exe,wintun.dll}`, `core\arm64\{mihomo.exe,wintun.dll}` — необязательная «заготовка» для установки без интернета.
  Версии и SHA-256 архивов — в `core.lock`.

## Сборка
`build.cmd` (достаточно Windows с .NET Framework 4). Исходники — `MihomoBar.cs`, `app.manifest`.

## Данные
`%ProgramData%\MihomoBar\`: `config.yaml`, `config.prev.yaml`, `settings.json`, `mihomo.log`, `core\` (ядро), панель `ui\` и геоданные.

## Блокировка интернета
Правило Брандмауэра Windows `MihomoBar-Block` (исходящий, весь публичный интернет; LAN, link-local и loopback остаются).
Включается после 5 неудачных перезапусков, снимается выходом из программы. Вручную:
`netsh advfirewall firewall delete rule name=MihomoBar-Block` (консоль администратора).

## Автозапуск
Пункт «Запускать при входе» создаёт задачу планировщика `MihomoBar` с наивысшими правами (без запроса UAC при входе).

## Самопроверка
`MihomoBar.exe --selftest <config.yaml> <отчёт.txt>` (от администратора): установка конфига, запуск ядра, API,
блокировка/снятие, автозапуск, остановка. Тестовый конфиг: `selftest.yaml` (режим DIRECT, TUN).
